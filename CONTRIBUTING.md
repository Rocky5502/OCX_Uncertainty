# Contributing

Contributions that improve reproducibility, benchmark adapters, uncertainty
estimation, validation, or documentation are welcome.

1. Open an issue describing the intended change and its evidence boundary.
2. Create a focused branch and preserve frozen experiment configurations.
3. Add tests for behavioral changes.
4. Run `make release-check`.
5. Submit a pull request with the commands and artifacts used for validation.

Do not commit credentials, participant data, private tests, proprietary source,
or a manuscript. Do not tune a frozen method on confirmatory task outcomes.
