# Episode and Post-Study Questionnaire

After each task:

1. Was the starting implementation correct? yes/no.
2. Confidence in that judgment, 0--100.
3. Final implementation confidence, 0--100.
4. Perceived difficulty, 1--5.
5. Guidance usefulness, 1--5, with `not shown` permitted in generic review.
6. Optional action category: accepted, edited API use, requested/used context,
   rejected similar-code assumptions, changed implementation logic, other.

After all tasks:

1. Short NASA-TLX mental demand, effort, frustration, and temporal demand,
   each 0--20.
2. Which information was most useful and why?
3. When did uncertainty information feel misleading?
4. Would you use this guidance during real code review? 1--5.

Free text must be screened for identifying information before public release.
